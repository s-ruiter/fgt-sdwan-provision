WAN-emulatie (LXC wan-emu, altijd mee bij FortiGate-VM's)

De container routeert tussen ISP-HUB (hubs, vast IP), ISP-A (wan1 van de spokes) en ISP-B (wan2), geeft de spokes een DHCP-reservering en doet NAT naar het lab via de uplink. Latency, jitter, loss en bandbreedte per link stel je in op de pagina WAN-emulatie.

03Topologie

Vast: regio West (AS 65001), loopback-summary 10.200.1.0/24, health-check-loopback Lo-HC 10.200.99.1/32 op elke hub (de branches meten daar naartoe via elke tunnel), DNS 1.1.1.1 en 8.8.8.8, wan1 allowaccess ping https ssh fgfm, platform FortiGate-VM64. De IPsec-PSK genereert de tool zelf (willekeurig, per ADOM bewaard).

VRF's

FortiGates: wachtwoord & licentie

Per FortiGate vul je hieronder het serienummer en het FortiFlex-token in. Hubs hebben één WAN (wan1, statisch IP + gateway); branches gebruiken wan1 en optioneel wan2, altijd via DHCP. Elke branch-WAN krijgt een tunnel naar wan1 van elke hub. De tool maakt de VM's via Day-0 (cloud-init) op Proxmox: IP, wachtwoord, FMG-koppeling en token gaan mee in de config-drive.

    01Storingen

    Over
    
      
    
        
    01Wat doet deze tool?
    
        
    Rolt via FortiManager 8.0 een SD-WAN/ADVPN-topologie met meerdere VRF's uit (hubs en branches in één regio). De tool maakt in FortiManager native templates aan (metadata-variabelen, system-, SD-WAN- en CLI-templates, policy packages, template groups en blueprints), afgeleid van Fortinet's Orchestrator — geen Jinja in FortiManager. De tool kan ook de VM's zelf op Proxmox aanmaken (Day-0 met FortiFlex) of bestaande VM's bootstrappen over SSH.
